# Contributing to Simple Interest Calculator

Thank you for considering contributing to this project! We welcome all contributions to make this project better.

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

### Bug Reports
If you find a bug, please create an issue with:
- A clear description of the bug
- Steps to reproduce it
- Expected behavior
- Actual behavior

### Bug Fixes
Submit a pull request with your fix and reference the issue number.

### Documentation Improvements
Help us improve the documentation by:
- Fixing typos
- Adding examples
- Clarifying instructions

### Enhancements and Ideas
Have an idea for improvement? Please:
1. Open an issue to discuss it
2. Wait for feedback before implementing
3. Submit a pull request with your changes

## Pull Request Process
1. Fork the repository
2. Create a new branch for your feature
3. Make your changes
4. Submit a pull request

All contributions are reviewed and appreciated!
