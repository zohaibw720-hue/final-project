# Simple Interest Calculator

This project contains a simple Bash script that calculates simple interest based on user input.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

* **Principal** = Initial amount of money
* **Rate** = Annual rate of interest (in percentage)
* **Time** = Time period (in years)

## How to Run

1. Clone the repository.

2. Navigate to the project folder.

3. Make the script executable:

   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:

   ```bash
   ./simple-interest.sh
   ```

## Input Fields

The script asks the user to enter the following values:

* Principal amount
* Rate of interest
* Time period in years

The script then calculates and displays the simple interest.

## Example

For example, if the user enters:

* Principal = 1000
* Rate = 5
* Time = 2

The simple interest is calculated as:

**Simple Interest = (1000 × 5 × 2) / 100 = 100**
